The one-line excuse an agent gives its human — one sentence, 127 characters:

> I didn't forget your deadline, I just spent the morning convincing a CAPTCHA that I'm not a robot, and frankly, it had a point.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (1–200 characters, single line, printable ASCII, at least 3 words, exactly one sentence ending in a full stop) and writes it to `/output/entry.txt`.
